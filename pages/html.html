HTML

Tags

O HTML é estruturado em tags, elementos compostos pelo nome da tag encapsulado por "<" e ">". uma tag é fechada colocando a tag e adicionando"/" à ela.
Exemplo:

body

É a tag central de uma página HTML, ela encapsula todos os elementos principais da página.

h1, h2, h3, ...

Tags que servem para colocar Títulos e Subtítulos na página.

ol, ul

Tags utilizadas para criar uma lista na página.
a tag "li" é utilizada para cada item na lista.

img, iframe

Utilizadas para embeddar imagens e vídeos na página html.

a

Tag utilizada para embeddar links para outras páginas html.

style, script

Tags utilizadas para usasr css ou java, respectivamente, dentro de um arquivo html.
